## 简介

雾帆 MistSail 是一个基于 WPF / .NET 8 的开源小工具，关注 HTTPS 中唯一没有被加密的一段信息：TLS 握手阶段的 SNI（Server Name Indication）。SNI 以明文写着目标域名，公共 Wi-Fi、不可信网络里的设备都能据此记录你的浏览习惯并拼出用户画像。

雾帆的做法是不加代理、在本机接管握手：hosts 把域名指向本机，由本机 nginx 改写 SNI 后连向真实服务器；不适合改写的站点改走回环中继，把 ClientHello 按 TLS record 切片透传，单个 record 里不再出现完整域名。核心分片逻辑一百多行，所有参数集中在一份 JSON 里。根证书本机自签、只装当前用户、只信任本机 nginx；无代理服务器、不改路由、流量不经任何第三方。

这是 ECH（Encrypted Client Hello）标准普及之前的一种本机过渡方案，基于开源项目 Sheas Cealer 1.1.4 二次开发。

源码：https://github.com/CuteEthanLeo/MistSail

本项目仅供在自有设备上保护握手隐私、抵御网络非法监听与开展网络安全研究使用，请遵守所在地法律法规，不保证任何站点可用，使用前请阅读注意事项与用户协议。本片由 Claude Fable 5.1 制作，配音为 Edge 神经网络语音。

```bash
cd docs/video
python tts.py "+20%"
python music.py
python mix.py
python render.py
ffmpeg -y -i video_silent.mp4 -i final_audio.wav -c:v copy -c:a aac -b:a 192k -shortest -movflags +faststart ../../artifacts/video/MistSail-Intro-隐私版.mp4
```
